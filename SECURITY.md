# Política de Seguridad

## Alcance

Este repositorio contiene exclusivamente documentación en formato Markdown (plantillas de listas de chequeo). No incluye código ejecutable, dependencias de software ni datos personales de aprendices o instructores.

Las listas de chequeo son plantillas en blanco; los datos diligenciados (fichas, nombres, calificaciones) **no deben subirse a este repositorio**.

---

## Reportar un problema de seguridad o privacidad

Aunque el riesgo técnico es bajo, si identificas alguno de los siguientes casos, repórtalo:

- Un archivo subido por error que contenga datos personales (nombres, documentos, calificaciones reales).
- Un enlace o contenido en la documentación que apunte a un sitio malicioso.
- Cualquier otro riesgo a la privacidad de aprendices o instructores.

### Cómo reportar

1. **No abras un issue público** si el reporte involucra datos personales.
2. Contacta directamente al mantenedor mediante los canales institucionales del SENA o abre un issue marcado como `security` con el mínimo detalle necesario.
3. El mantenedor responderá en un plazo máximo de **5 días hábiles**.
