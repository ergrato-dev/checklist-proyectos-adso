# Estructura de cada lista

Cada lista de chequeo está organizada en cinco dimensiones que aplican en todos los trimestres, aunque con distinto peso según el momento del proceso formativo:

*Dimensión 1* — Gestión del Proyecto evalúa si el equipo usa herramientas de seguimiento (Jira, Trello, GitHub Projects. ClikUp), si hay un backlog organizado, si las actas de reunión están al día y si los roles del equipo están definidos y funcionando.

*Dimensión 2* — Artefactos Técnicos del Trimestre evalúa los entregables específicos que el RAP del trimestre exige: diagramas, modelos, código fuente, APIs, bases de datos, etc.

*Dimensión 3* — Documentación -> evalúa que la documentación sea relevante y esté bajo estándares (no "documentación por relleno"), incluyendo control de versiones del documento.

*Dimensión 4* — Trabajo en Equipo y Proceso evalúa evidencias de colaboración real: commits distribuidos en el repositorio, distribución equitativa de tareas, participación en la sustentación.

*Dimensión 5* — Calidad y Mejores Prácticas evalúa que el equipo aplique criterios de calidad propios del trimestre: convenciones de código, revisión entre pares, pruebas cuando aplica.
